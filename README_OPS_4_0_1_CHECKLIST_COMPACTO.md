# OPS 4.0.1 — Checklist limpio y comentarios compactos

- El panel del técnico filtra encabezados, especialidades y nombres completos que quedaron en checklist de OTs antiguas.
- Al guardar avance o enviar a revisión, se envía el checklist limpio para corregir esos registros heredados.
- El expediente del administrador aplica el mismo filtro visual.
- Los comentarios por actividad aparecen al frente de la actividad, en una caja compacta de una línea con placeholder.
- El lector PDF sigue tomando las actividades únicamente del bloque de actividades y no debe incorporar las secciones de personal o materiales.

Nota: si una OT antigua quedó contaminada, el técnico debe abrirla y guardar el avance para persistir el checklist limpio. Las OTs nuevas deben crearse de nuevo desde el PDF original para utilizar la extracción actualizada.
